# C++ — Language Overview & Notes

## About the Language
- **Type:** Compiled, General-Purpose, Multi-paradigm, Statically Typed.
- **Core Strengths:** Zero-overhead abstractions, direct hardware access, complete control over memory and system resources.
- **Primary Use Cases:** Game engines, OS kernels, low-latency trading, browser engines, embedded systems, reverse engineering tools.

---

## Key Features & Mechanics
- **Resource Management:** Resource Acquisition Is Initialization (RAII) ensures deterministic object destruction and memory cleanup.
- **Compilation Model:** Native compilation to machine code via CMake/Ninja and compilers like MSVC, Clang, or GCC.
- **System Power:** Full access to WinAPI, NTAPI, inline assembly, and direct memory pointers.
